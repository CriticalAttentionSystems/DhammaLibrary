Connect shared editing

The editor needs a GitHub repository and a working sign-in connection before it can save contributions.

  1. Place the project in a public GitHub repository with a main branch and connect it to Netlify.
  2. Set the build settings GITHUB_REPOSITORY (owner/repository) and SITE_URL (the live HTTPS address), then redeploy.
  3. Create a GitHub OAuth App with callback https://api.netlify.com/auth/done. Enter its Client ID and secret directly in Netlify's Project configuration → Security → OAuth.
  4. Return to the editor and test GitHub sign-in. Verify a contributor can submit a draft and that the owner can review and merge its pull request.

Keep credentials out of this site's files. The full instructions are in docs/SHARED-EDITOR.md in the project.
